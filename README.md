# SpecterOS v7.4 — راهنمای جامع و دقیق اجرای سامانه
### Secure Offensive Operations Console & Termux Platform

این مستند شامل دستورات دقیق، خط به خط و بدون خطا برای راه‌اندازی و اجرای سامانه بر روی **گوشی‌های اندروید (ترموکس / Termux)** و همچنین **سیستم‌های دسکتاپ (لینوکس، ویندوز، مک)** می‌باشد.

---

## 📱 بخش اول: راهنمای اجرا در ترموکس اندروید (Termux)

### مرحله ۱: ورود به پوشه پروژه و اعطای مجوز اجرا (فقط یک‌بار)

برنامه Termux را باز کرده و با دستور `cd` وارد پوشه پروژه شوید:

```bash
cd /مسیر_پوشه_پروژه
```

سپس دستور زیر را برای اعطای مجوز اجرایی وارد نمایید:

```bash
chmod +x alikakai install.sh start.sh
```

---

### مرحله ۲: نصب خودکار و ثبت دستور سراسری (فقط یک‌بار)

دستور زیر را اجرا کنید تا پیش‌نیازها و وابستگی‌ها نصب شده و دستور `alikakai` در ترموکس ثبت گردد:

```bash
./install.sh
```

> **نکته:** اسکریپت `install.sh` تمام بسته‌های مورد نیاز (`nodejs-lts`, `git`, `curl`, `unzip`) را بررسی و نصب می‌کند و دستور اختصاصی را به مسیر باینری ترموکس (`$PREFIX/bin/alikakai`) منتقل می‌نماید.

---

### مرحله ۳: اجرای پروژه (همیشه و از هر مسیری)

از این به بعد، **از هر پوشه و مسیری در ترموکس**، فقط کافی است این دستور تک‌کلمه‌ای را بنویسید و اینتر بزنید:

```bash
alikakai
```

پروژه بلافاصله اجرا شده، وضعیت پورت را بررسی می‌کند و لینک‌های دسترسی را نمایش می‌دهد:
- **آدرس داخلی گوشی:** `http://localhost:3000` (یا پورت آزاد بعدی)
- **آدرس شبکه وای‌فای/هات‌اسپات:** `http://IP_گوشی:3000` (قابل باز شدن در سایر گوشی‌ها و لپ‌تاپ‌های متصل به شبکه)

مرورگر گوشی شما نیز به‌صورت خودکار باز خواهد شد.

## ⚡ سوئیچ‌های کاربردی دستور `alikakai` در ترموکس

| دستور | کاربرد و نتیجه |
|---|---|
| `alikakai` | اجرای عادی و خودکار سامانه (پیش‌فرض) |
| `alikakai --stop` | متوقف کردن سرور در حال اجرا در پس‌زمینه با PID اختصاصی |
| `alikakai --status` | بررسی وضعیت آنلاین/آفلاین بودن سرور و شماره پورت |
| `alikakai --ip` | استخراج و نمایش تمام IPهای محلی و شبکه LAN |
| `alikakai --info` | مشاهده مشخصات پردازنده، نسخه Node.js و بستر اجرایی |
| `alikakai --debug` | اجرای کنسول در حالت دیباگ با نمایش خط به خط لاگ‌ها |
| `alikakai --clean` | پاکسازی کش موقت و لاگ‌های قدیمی |
| `alikakai --reinstall` | حذف کامل و نصب مجدد و تازه کتابخانه‌ها |
| `alikakai --build` | ساخت نسخه نهایی و پروداکشن پروژه |
| `alikakai --prod` | اجرای سرور پروداکشن (`vite preview`) |
| `alikakai --help` | مشاهده راهنمای تمام گزینه‌ها |

## 💻 بخش دوم: راهنمای اجرا در کامپیوتر (ویندوز / لینوکس / مک)

اگر قصد دارید پروژه را روی لپ‌تاپ یا سرور دسکتاپ اجرا کنید، دو روش زیر در دسترس است:

### روش ۱: استفاده از اسکریپت سریع Bash (لینوکس / مک / WSL ویندوز)

```bash
chmod +x ./start.sh
./start.sh
```

### روش ۲: استفاده از دستورات استاندارد Node.js / NPM

۱. نصب وابستگی‌ها (فقط بار اول):
```bash
npm install
```

۲. اجرای سرور توسعه:
```bash
npm run dev
```

سپس در مرورگر خود آدرس زیر را باز کنید:
```text
http://localhost:3000
```

## ⌨️ کلیدهای میانبر درون سامانه (برای کاربران حرفه‌ای)

هنگامی که سامانه در مرورگر باز است:

- **`Esc`**: پاکسازی فوری متن داخل کادر دستورات ترمینال
- **`Ctrl+L`** یا **`Cmd+L`**: پاکسازی لاگ‌های جاری ترمینال
- **`Tab`**: جابه‌جایی آنی فوکوس بین کادر ورودی دستور و پنل‌های عملیاتی (نقشه و مانیتورینگ)
- **`Alt+1` تا `Alt+4`**: سوییچ مستقیم بین پنل‌های Terminal، Network Map، Breach Monitor و Log Stream
- **کلیدهای جهت‌نما (↑ و ↓)**: پیمایش در تاریخچه دستورات قبلی (Command History)

## 🛠 رفع اشکال (Troubleshooting)

۱. **اگر پورت ۳۰۰۰ اشغال بود:**
   اسکریپت `alikakai` به‌صورت هوشمند پورت‌های بعدی (۳۰۰۱ تا ۳۰۲۵) را پیدا کرده و متصل می‌شود؛ هیچ نیازی به دخالت دستی نیست.

۲. **اگر سرور در پس‌زمینه باز مانده بود:**
   دستور زیر را بزنید تا پروسه به‌صورت امن بسته شود:
   ```bash
   alikakai --stop
   ```

۳. **جلوگیری از توقف ترموکس هنگام خاموش شدن صفحه گوشی:**
   در ترموکس دستور زیر را اجرا کنید تا اندروید اجازه به خواب رفتن پردازه را ندهد:
   ```bash
   termux-wake-lock
   ```
