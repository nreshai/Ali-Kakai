# SpecterOS v7.4 — راهنمای اختصاصی و گام‌به‌گام اجرای ترموکس (Termux)

این راهنما حاوی دستورات دقیق برای راه‌اندازی و اجرای بدون نقص سامانه بر روی Termux در سیستم‌عامل اندروید است.

---

## ۱. نصب و آماده‌سازی اولیه (فقط یک‌بار)

ابتدا با دستور `cd` وارد دایرکتوری پروژه شوید و دو دستور زیر را به نوبت اجرا کنید:

```bash
# گام اول: اعطای دسترسی اجرایی به اسکریپت‌ها
chmod +x alikakai install.sh start.sh

# گام دوم: اجرای اسکریپت نصب و پیکربندی خودکار
./install.sh
```

### عملیاتی که اسکریپت `./install.sh` انجام می‌دهد:
1. پکیج‌های پیش‌نیاز (`nodejs-lts`, `git`, `curl`, `unzip`) را بررسی و نصب می‌کند.
2. نسخه Node.js را چک کرده و در صورت نیاز نسخه ۱۸ به بالا را تنظیم می‌کند.
3. وابستگی‌های پروژه (`npm install`) را نصب و در هش اختصاصی کش می‌کند.
4. دستور اجرایی سراسری را در مسیر `$PREFIX/bin/alikakai` کپی می‌کند تا از هر جای گوشی قابل فراخوانی باشد.

---

## ۲. دستور اجرای همیشگی سامانه

پس از اتمام مرحله نصب، در هر زمان و **از هر پوشه‌ای در ترموکس**، تنها با تایپ این دستور، پروژه فعال می‌شود:

```bash
alikakai
```

بلافاصله سرور بالا آمده و خروجی شبیه به زیر را مشاهده خواهید کرد:
```text
SpecterOS Console Access Points:
  👉 Local Loopback:   http://localhost:3000
  👉 Internal IP:      http://127.0.0.1:3000
  👉 Mobile/Wi-Fi LAN: http://192.168.1.X:3000
```
مرورگر گوشی شما به‌صورت خودکار لینک را باز خواهد کرد. همچنین دستگاه‌های دیگر روی همان شبکه وای‌فای یا هات‌اسپات با زدن آدرس LAN می‌توانند به داشبورد دسترسی داشته باشند.

## ۳. سوئیچ‌های کاربردی دستور `alikakai`

| دستور | نتیجه اجرا |
|---|---|
| `alikakai` | اجرای عادی و خودکار سامانه (پیش‌فرض) |
| `alikakai --stop` | متوقف کردن سرور پس‌زمینه با PID دقیق و ایمن |
| `alikakai --status` | بررسی وضعیت فعال بودن سرور، شماره پورت و PID |
| `alikakai --ip` | نمایش آی‌پی‌های لوکال و شبکه محلی وای‌فای |
| `alikakai --info` | نمایش اطلاعات کامل سیستم، مشخصات سخت‌افزاری و نسخه نرم‌افزارها |
| `alikakai --debug` | اجرای کنسول در حالت دیباگ با مشاهده جزئیات لاگ‌ها در ترمینال |
| `alikakai --clean` | پاکسازی کش وابستگی‌ها، لاگ‌ها و فایل‌های موقت |
| `alikakai --reinstall` | حذف کامل پوشه node_modules و نصب مجدد و بدون نقص تمام پکیج‌ها |
| `alikakai --build` | کامپایل بیلد Production |
| `alikakai --prod` | اجرای سرور پروداکشن بر روی هاست و پورت اختصاصی |
| `alikakai --help` | نمایش راهنمای کامل دستورات |

## ۴. نکات مهم در ترموکس

1. **جلوگیری از قطع شدن سرور هنگام خاموش شدن صفحه گوشی:**
   در ترموکس دستور زیر را اجرا کنید:
   ```bash
   termux-wake-lock
   ```
2. **بستن دستی سرور:**
   می‌توانید کلیدهای `Ctrl + C` را در ترمینال بزنید یا در پنجره‌ای دیگر دستور `alikakai --stop` را تایپ کنید.
